=== Fotospur ===
Requires at least: 6.5
Requires PHP: 7.4
Stable tag: 1.0.0
License: MIT

Block „Fotospur“: Fotos einer Tour an der Stelle der Tourspur-Strecke, an der sie aufgenommen wurden.

== Benutzung ==

1. In einem Beitrag den Block „Fotospur“ einfügen.
2. „GPX-Datei auswählen“: die aus Tourspur exportierte GPX-Datei hochladen oder auswählen.
3. „Fotos auswählen“: die Fotos der Tour hochladen oder auswählen.

Der Block liest Aufnahmezeit und Ort aus den Fotos und setzt sie an die passende Stelle der Strecke.
Fotos ohne diese Angaben werden in der gewählten Reihenfolge verteilt; ein Hinweis darauf ist nur für angemeldete Redakteure sichtbar.
Die Strecke wird ohne Kartendienst gezeichnet, es werden keine Daten an Dritte übertragen.
